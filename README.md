# 🗄️ MYSD - Modelos y Servicios de Datos

Bienvenido al repositorio de la asignatura **Modelos y Servicios de Datos (MYSD)**. Este espacio contiene los talleres, laboratorios, modelos conceptuales y scripts desarrollados durante el curso de Bases de Datos Relacionales.

---

## 🛠️ Herramientas y Tecnologías Utilizadas

* **Gestor de Base de Datos:** Oracle Database / PostgreSQL / MySQL
* **Entorno de Trabajo / Cliente SQL:** **SQL Developer** (u otro gestor gráfico SQL)
* **Lenguaje:** SQL (DDL, DML, DCL, TCL)
* **Modelado:** Oracle SQL Developer Data Modeler / Diagrams.net

---

## 📚 Temario y Contenidos Clave

A lo largo del curso se abordan los conceptos fundamentales para el diseño, implementación y consumo de bases de datos relacionales:

### 1. Modelado Conceptual y Lógico
* **Modelo Entidad-Relación (E-R):** Entidades, atributos, llaves primarias, llaves foráneas y cardinalidades.
* **Modelo Relacional:** Conversión de diagramas E-R a tablas relacionales y reglas de integridad de datos.
* **Normalización:** Formas normales (1FN, 2FN, 3FN) para la eliminación de redundancias y anomalías.

### 2. Lenguaje de Consulta Estructurado (SQL)
* **DDL (Data Definition Language):** Creación, modificación y eliminación de estructuras (`CREATE`, `ALTER`, `DROP`).
* **DML (Data Manipulation Language):** Insertar, actualizar, eliminar y consultar información (`INSERT`, `UPDATE`, `DELETE`, `SELECT`).
* **Consultas Avanzadas:** 
  * Cláusulas `GROUP BY`, `HAVING`, `ORDER BY`.
  * Uniones (`JOIN`, `LEFT JOIN`, `RIGHT JOIN`).
  * Subconsultas y funciones de agregación (`SUM`, `AVG`, `COUNT`, `MAX`, `MIN`).

### 3. Servicios, Objetos Avanzados e Integridad
* **Restricciones de Integridad:** `PRIMARY KEY`, `FOREIGN KEY`, `CHECK`, `UNIQUE`, `NOT NULL`.
* **Vistas (Views) e Índices:** Optimización de lectura y abstracción de datos.
* **Transacciones (TCL):** Control de transacciones con `COMMIT` y `ROLLBACK`.
